## 🔧 2. التعديل الجراحي الجوهري لشيفرة `solver.py`

المشروع الأصلي المستنسخ من GitHub كان يعاني من عطل قاتل يؤدي لـ `Timeout 500`:
- **الخلل القديم:** كان الكود ينفذ أمراً تعسفياً:
  ```javascript
  window.stop();
  document.body.innerHTML = '';
  ```
  هذا الأمر كان يجهض طلبات الشبكة قبل اكتمال تحميل سكريبت كلوفلاير `challenges.cloudflare.com/turnstile/v0/api.js` مما يمنع ظهور الويدجت وتجميد العملية.
- **الحل الميداني المعتمد:**
  1. إلغاء `window.stop()` نهائياً والحفاظ على سياق دومين الصفحة حياً.
  2. اعتماد حاوية حقن آمنة `#cf-auto-container` مع خطاف التحميل `onload=cfAutoLoaded`.
  3. تفعيل صمام **الالتقاط المزدوج (Double-Catch)**: قراءة التوكن من الـ Callback الرسمي `window._cf_extracted_token` بالتوازي مع قراءة حقل الـ DOM الخفي `[name="cf-turnstile-response"]`.
  4. تخطي فحص الأتمتة لمنصة PixVerse (تجاوز خطأ `500223`) عبر تزويد طلبات التسجيل بهيدرز متصفح كاملة (`x-device-id`, `ai-anonymous-id`, `x-platform: Web`).

## 🚀 3. التشغيل الذاتي بنقرة واحدة (1-Click Lifecycle)

تم تصميم أدوات تحكم تنفيذية سهلة جداً على نظام Windows:

| الملف التنفيذي | الوظيفة ودليل الاستخدام |
|---|---|
| **`create_account.bat`** | **زرار المصنع (الإنشاء التلقائي):** يشغل السيرفر في الخلفية تلقائياً، يطلب منك الإيميل، يحل الكابتشا، يستقبل الـ OTP، ويفعل الحساب ويحفظه في ثوانٍ. |
| **`check_credits.bat`** | **كشف الرصيد الفوري:** يعرض رصيد النقاط المتبقية لكافة الحسابات المسجلة. |
| **`start_solver.bat`** | **تشغيل السيرفر صامتاً:** يطلق خادم `service.py` في الخلفية كـ Daemon خفي على بورت `8191`. |
| **`stop_solver.bat`** | **إيقاف السيرفر وتنظيف الذاكرة:** يغلق عمليات بايثون وكروم المرتبطة بالبورت لتوفير الرام. |
| **`run_all_tests.bat`** | **حزمة الاختبارات الشاملة:** فحص ذاتي لبيئة بايثون، كروم، صحة السيرفر، وتوليد توكن حي (4/4 Passed). |

## 💻 4. أوامر سطر الأوامر (CLI Usage)

### 1. تشغيل حزمة الاختبارات الشاملة:
```powershell
python run_all_tests.py
```

### 2. فحص رصيد الحسابات:
```powershell
python pixverse_creator.py --credits
```
أو لحساب محدد:
```powershell
python pixverse_creator.py --account ispat545ailbc --credits
```

### 3. إرسال محادثة ذكاء اصطناعي (مع موديل gpt-6-astra مجاناً):
```powershell
python pixverse_creator.py --chat "اكتب لي سيناريو فيديو وثائقي"
```

### 4. توليد فيديو بالذكاء الاصطناعي (Text-to-Video):
```powershell
python pixverse_creator.py --video "cinematic drone view of Cairo at sunset, 4k ultra-realistic"
```
